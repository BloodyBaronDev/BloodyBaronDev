# Bloody Baron

Тихий огонь, долгий код. Строю сервисы, которые работают, пока все спят.

Занимаюсь бэкендом и серверной инфраструктурой: от кода и базы до сети, деплоя и мониторинга. Пишу на Python и TypeScript, делаю клиентские приложения и поддерживаю то, что написал, в проде.

## Чем занимаюсь

- **Бэкенд:** веб-сервисы, API, Telegram-боты, интеграции с платёжными системами
- **Инфраструктура:** Linux, Docker, Nginx, CI/CD
- **Сеть и защита серверов:** Xray, iptables, ipset, защита от сканирования
- **Клиенты:** приложения для Windows, Android и iOS

## Открытые проекты

| Проект | Что это | Стек |
|---|---|---|
| [infinity-xray](https://github.com/BloodyBaronDev/infinity-xray) | Серверная сборка Xray: keepalive для тихих соединений, governor HTTP/2 для XHTTP и диагностика mux | Xray-core, Docker |
| [infinity-scanblock](https://github.com/BloodyBaronDev/infinity-scanblock) | Отсекает сканеры интернета на входе в сервер: публичные списки, ipset и iptables | Bash, systemd |

Остальная работа живёт в приватных репозиториях.
